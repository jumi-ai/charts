# charts

Helm charts for Jumi. The installable chart is [charts/jumi](charts/jumi). Install steps are in [charts/jumi/README.md](charts/jumi/README.md). Chart `0.2.0` tracks Jumi `v10.4.0` (router, control, one-shot Jobs per ledger row).

A tag `jumi-vX.Y.Z` matching `charts/jumi/Chart.yaml` `version` publishes `oci://ghcr.io/jumi-ai/charts/jumi` and a GitHub Release with the packaged chart.
